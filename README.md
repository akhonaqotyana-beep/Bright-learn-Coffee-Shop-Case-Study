# Bright-learn-Coffee-Shop-Case-Study
Repo contains a case study on Bright learn Coffee shop where an analysis was conducted, it captures
daily transactional information from a coffee shop.


The request was that I extract actionable insights from historical data and prepare a presentation to assist the CEO in decision-making.

Used analytics, SQL, and data visualization skills to help Bright Coffee Shop understand:
Which products generate the most revenue and at what time of day the store performs best.

# Tasks Completed
-- Miro planning and Gantt Chart that outlines the plan of the Analysis.

-- Databricks SQL Analysis with necessary calculations

-- Exported Results CSV file of the Bright-learn coffee shop

-- Pivot table Visualisation answering the requirements of the best performing products.
